Корректный ответ должен использовать модель зарядки RC-цепи:
U_C(t) = U0 * (1 - exp(-t / tau)), tau = R * C.

При U0 = 12 В, R = 10 кОм = 10000 Ом, C = 470 мкФ = 0.00047 Ф:
- tau = 4.7 с
- U_C(1 с) примерно 2.30 В
- U_C(3 с) примерно 5.66 В
- U_C(5 с) примерно 7.86 В
- t_90 = -tau * ln(0.1) примерно 10.82 с
